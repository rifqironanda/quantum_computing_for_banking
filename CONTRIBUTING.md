# Panduan Kontribusi

1. Buat branch dari `main`.
2. Ubah materi di `src/slides.js` atau komponen terkait.
3. Jalankan `npm install` jika dependency belum tersedia.
4. Jalankan `npm run build` sebelum commit.
5. Pastikan navigasi keyboard, fullscreen, dan tampilan mobile tetap berfungsi.
6. Gunakan sumber primer ketika mengubah klaim ilmiah atau regulasi.

Gunakan commit message yang menjelaskan maksud perubahan, misalnya `docs: perbarui referensi NIST` atau `feat: tambah visualisasi Mosca timeline`.
